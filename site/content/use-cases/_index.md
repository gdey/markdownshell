title: Use cases
description: Runbooks, reports and checklists people keep in mdsh documents, with sample reports.
---

An mdsh document is the steps and the record of running them, in one
markdown file. That suits work that is done by hand today from a wiki page
or a README: the page becomes something you run, and the run becomes a
report you can send.

Each use case below comes with a runbook from
[examples/runbooks](https://github.com/gdey/markdownshell/tree/main/examples/runbooks)
and the report one run of it made, as PDF, HTML and markdown. CI runs every
runbook there on each change, so they keep working.
