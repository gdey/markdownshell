mdsh runs the code blocks in a markdown file, like a notebook whose file
format is plain markdown. Start with getting started, then the desktop app
or the terminal UI, then the document format. For a guided tour by
example, see [the examples]({{< relref "/examples" >}}). The
[cheat sheet]({{< relref "cheatsheet" >}}) has every attribute, flag and
key on one page.
