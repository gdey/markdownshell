Disk usage report

A weekly look at disk space: how full each file system is, and what is using the space in one directory. Every block only reads. Set DIR to the directory to look into; it defaults to this repository's examples directory so the report is quick to run.

The file systems that hold DIR, your home directory and the temporary directory, fullest first. df -P prints the same columns on Linux and macOS.
