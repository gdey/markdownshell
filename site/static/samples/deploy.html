Deploy the docs site

This runbook builds a small static site, checks it, and ships it as a new release behind a current symlink, the way many hosts serve static sites. "Production" is a scratch directory under $TMPDIR, so running it changes nothing on your machine. Swap the build and ship blocks for your own commands to use it for real.

The run stops at the first failing step (on_error: stop), and shipping asks first (confirm). mdsh --yes answers yes for you, as CI would.

Build

Check

Two checks run side by side. The link checker is a background block: it starts, and the run goes straight on to the size check below while it works.

Before shipping, wait for the link checker. wait gives its exit status, so broken links stop the run here.

Ship

Copy the build into a new release directory, then point the current symlink at it, so visitors never see a half-copied site.

Verify

What production serves must match what was built.
