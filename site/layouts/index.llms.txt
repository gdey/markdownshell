# mdsh

> {{ site.Params.description }}

mdsh runs the code blocks in a markdown file, in order, like a notebook
whose file format is plain markdown. Each block's output is written back
into the file under the block, so a document is both the runbook and the
record of its last run. The same document runs from the command line
(`mdsh file.md`), in a terminal UI (`mdsh -i file.md`), in a desktop app
(`mdsh-gui file.md`) and in a browser (`mdsh --serve file.md`), and a run
can be written out as markdown, HTML or PDF.

A document is ordinary markdown: every `sh` and `zsh` fence runs, in
the same long-lived shell, and other languages are left alone; attributes
in braces after the language (`{#id env=name depends=other}`) name a
block, pick its env and order it; `textbox`, `choice`, `http`, `include`
and `output` fences are the other block kinds; and document-wide options
go under an `mdsh:` key in YAML front matter.

The full text of every docs page is at {{ "llms-full.txt" | absURL }}.
